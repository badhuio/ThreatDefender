## Features
- File Analysis
- URL Analysis
- AI Threat Detection
- MongoDB Storage
- MCP Integration

## Technologies
- Java
- Spring Boot
- MongoDB
- Gemini AI
- MCP

## How MCP Helps
MCP allows ThreatDefender to access external tools and resources to perform advanced threat analysis.
